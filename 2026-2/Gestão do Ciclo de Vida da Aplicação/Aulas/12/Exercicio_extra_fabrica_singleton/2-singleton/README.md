# Padrao Singleton

O codigo abaixo cria um novo objeto `GameLogger` em cada subsistema do jogo
(`sistemaDeCombate`, `sistemaDeConquistas`, `sistemaDeSave`). Refatore
aplicando o padrao **Singleton**, de forma que exista no maximo uma unica
instancia de `GameLogger` durante toda a execucao do jogo. Siga os TODOs
numerados no arquivo `Main.java`.
