# RetroGames MVC

Abra `app/Pedidos.csproj` em uma IDE com suporte a ASP.NET Core e SDK .NET 8. Execute o projeto pelo botão Iniciar/Executar e acesse http://localhost:8082.

Alternativa pelo terminal:

```bash
cd app
dotnet run
```

Use Ctrl+C para encerrar no terminal. O catálogo e os pedidos estão no mesmo processo; os pedidos são mantidos em memória e se perdem ao encerrá-lo. Não é necessário Docker.
